# File moves made when this folder became a git repository

On 2026-11-12 the unversioned research folder was reorganized into this
repository layout. Every move was non-overwriting and nothing was deleted.
Paper `.tex` sources were moved with their folders and not edited.
Paths are relative to the repository root. From the `lean-core` row on,
`lean/` in the left-hand column already means the renamed `lean-core/`.

Files under `docs/history/` are kept verbatim, so their internal relative links
still point at the old flat layout (for example `paper-a-lattice/`); use this
table to translate them.

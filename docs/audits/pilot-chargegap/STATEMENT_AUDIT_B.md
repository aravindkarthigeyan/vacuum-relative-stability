## Numerical method

All scripts are in `lean/.lake/scratch/caudB/` (untracked), run with `python -I`
(numpy 2.5.4, scipy 1.18.1, python-flint 0.9.0 for certified ball arithmetic).

**Literal re-implementation (`cg.py`, double; `cgarb.py`, Arb balls).** Sites of `(Z/3)^3`, one-particle
index `(x, s) ↦ 4x + s` (`ι × Fin 4`, spatial factor first), so Mathlib's `A ⊗ₖ B` is `kron(A, B)`.
`latticeShift`: `T[x, y] = conj(U[x, j])` iff `y = x + e_j`. `wilsonHopping = (2ia)^{-1}(T - T^H)`.
`wilsonMass = m·1 + (r/(2a)) Σ_j (2·1 - T_j - T_j^H)`. `diracOperator = Σ_j kron(v_j, α_j) + kron(M, β)`.
`Step.generator`: free `τ·h`, kick `-(i·kron(Θ, I_4))`. `transferMatrix`: the list of `exp(-generator)`,
reversed, then multiplied left to right (`[A1,…,Ak].prod = A1⋯Ak`), so later steps act on the left.
`centeredTrace = exp(½ Σ trace(generator)) · det(I + transferMatrix)`; the kick's centering is taken from
`Step.generator`, never hand-inserted. `Fhat p = (2π)^{-1} ∫_0^{2π} e^{-ipφ} F(φ) dφ` is computed as the
K = 112 point rectangle rule, which is exact here: `F` is a trigonometric polynomial with frequencies
in `[-d, d] = [-54, 54]` and `K > 2d`. Clifford sets: the standard Dirac matrices, and random unitary
conjugates of them (all Hermitian Clifford sets of size 4 arise this way; `F` is independent of the
choice, which is unique up to unitary equivalence). In Arb, every instance is exactly admissible: link
values `exp(i t)` and random Clifford sets `W α W^*` with `W = exp(iH)` are enclosures of exactly unitary
or exactly Clifford objects, and PSD masses are formed as `B B^H` inside ball arithmetic.

**Tiers.** (i) Double precision via `slogdet` for 144 random admissible instances restricted to
`b·h_* ≤ 10`, where double precision is reliable (`t3_double.py`). (ii) Certified Arb evaluation of 12
edge-case instances, checking every `Q ∈ [-54, 54]` (`t3_arb.py`). (iii) Explicit Fock space
(`focktest.py`). (iv) T4 in double and Arb (`t4.py`, `t4_confirm.py`, `t4_arb.py`). (v) Controls
(`deftests.py`, `insens.py`, `ctrl_neg2.py`). Dimensions throughout: n = 3, N = 27, D = 108, d = 54.

### T4 (`t4.py`, `t4_confirm.py`, `t4_arb.py`)

- (a) 60 Wilson histories with `m = 0` on n = 3 (14 with r = 0, i.e. `M = 0`), up to 10 free steps,
  with diagonal and non-diagonal Hermitian kicks interspersed and appended. (b) 200 generic histories,

  `log|F| ≥ 102`, that is `b‖h‖` in the hundreds, where double-precision `det(I + U)` is unreliable.
  The flagged phases are not reproducible between two identical runs (for example 0.97 then 0.74 for

- Arb re-evaluation of the flagged instances with `log|F| ≤ 300` (9 instances, |ι| = 5, 8, 27, at
  prec 594-1119): each one certified `Re F > 0` with the `Im F` ball containing 0. For example,
  instance 14 had a double phase of 1.81 and gives the certified value `8.14997e94`.
  The five flagged instances with `300 < log|F| ≤ 1200` were also re-evaluated at prec 2238-3590:
  generic 25, 146 and 158 (|ι| = 27, 27, 8) and the n = 3 Wilson `m = 0` instances 0 and 38
  (18 and 7 steps). Each one certified `Re F > 0` with the `Im F` ball containing 0; for example
  generic 158 had a double phase of 1.72 and gives the certified value `1.21532e151`. In total
  14 of the 26 flagged instances are certified positive and real, and none is negative. The other
  12 (`log|F|` from 2664 to 28094) were not re-evaluated because of cost. Double precision cannot
